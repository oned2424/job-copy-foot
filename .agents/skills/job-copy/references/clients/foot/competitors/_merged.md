## 4. FooT との構造差分（★最優先で読むセクション）

FooT の現行求人11件（`Joblist` 取得・2026-07-30時点）との比較。

| 観点 | FooT（現行11件） | ワールドインテック（Indeed） | 差 |
|---|---|---|---|
| **年齢の扱い** | **`年齢不問`・`10代から60代まで活躍中` ＝ 広く開く** | **`20-30代の男女活躍中` ＝ 狙って絞る** | ★**決定的** |
| 金額の位置 | 中盤（`高時給1700円`） | **冒頭・月額換算**（`月42万`） | 大 |
| 装飾記号 | `☆` `♪` `★` を多用 | **ゼロ** | 大 |
| 緊急性 | 無し | 有り（`7月入社あと3名`） | 中 |
| 作業の軽さ | `カンタンな`・`運ぶだけ` | `軽いモノだけ`・`ライン作業なし`・`モクモク` | 同等 |
| 応募障壁 | タグ側にはあるが本文に薄い | **タイトル本体に書く**（`履歴書ナシで応募可`） | 中 |

### 差分から導かれる、FooT の課題

FooT は11件中4件で `60代も応募可` タグを立て、キャッチコピーに `年齢不問`・`10代から60代まで活躍中` と書いている。

**媒体は、書いてある通りに人を集めている。**

20-30代が集まらないのは、媒体の性能ではなく **原稿が「全年齢」に向けて書かれているため**という説明が成り立つ。
これが本プロジェクトの起点（20-30代訴求）である。

### 生成時に適用すべき方向

| 変数 | FooT の現行 | 改善方向 |
|---|---|---|
| 金額の位置 | 中盤 | **冒頭へ移す。時給→月額換算も併記する**（変数1） |
| 装飾記号 | `☆♪★` 多用 | **削る。**競合はゼロで運用している |
| 職種名 | `カンタンな目視検査と仕分け作業` | **口語化を試す**（変数2） |
| 応募障壁 | タグ止まり | **タイトル本体に上げる**（変数4） |
| 緊急性 | 無し | **A/B案の片方に入れる**（変数5・S045） |
| 年齢 | `年齢不問`・`10代から60代まで` | **直接表現は使わない。**セクション8-2 の通り、間接訴求で置き換える |

**目立つ場所で絞り、目立たない場所で広げている。**
求職者が最初に見る面は 20-30代に向け、応募の間口自体は閉じていない。

FooT は同じ文言（`10代から60代まで活躍中`）を、**最も目立つキャッチコピー**に置いている。
つまり **FooT と競合の差は「何を書くか」ではなく「どの欄に置くか」**でもある。

| | 実行のしやすさ | 法令リスク |
|---|---|---|
| 年齢の直接表現を新たに書く | — | **高い。セクション8-2 の通り現時点で禁止** |

**→ ただし `20-30代` を新たに書き足すことは、セクション8-2 が解けるまで引き続き禁止。**

### ★ 2026-08-02 追記: 給与欄で「タイトルの金額」を裏付けている

競合はタイトルに `月36万` `月42万` と書いたうえで、**給与欄に内訳の計算式を必ず載せている。**

```
月収例：373,880円
（1,800円 × 156.6H ＋ 残業 2,250円 × 20H ＋ 深夜 450円 × 60H ＋ 通勤手当 20,000円）
```

タイトルの数字が誇大に見えないための担保になっている。

**→ 生成時: 金額をタイトル前方に出す案を作るなら、給与欄に月収例の内訳が入るかを必ず確認する。**
**→ 内訳の根拠（実働時間・残業時間・深夜時間）が取れないなら、その案では金額を前に出さない。**

## 10. 本文（仕事内容）の書き出しの型

**2026-08-02 追加。**セクション1〜9はタイトルの分析。ここからは本文。

同じ求人IDの中で **書き出しが11通りすべて違う。**
タイトルの言い換えより変化幅が大きい。**競合のA/Bテストの本体はここにある可能性が高い。**

| 型 | 骨格 | 実測された書き出し（短縮） |
|---|---|---|
| **Q&A型** | 質問文 → 一文で答える | `Q：どんなお仕事ですか？ A：〜がメインのお仕事です！` |
| **ハッシュタグ型** | `＃` で条件を2〜3個並べる | `＃日勤のみだから働きやすい◎しかも土日休み！ ＃なのに月36万稼げるんです！` |
| **罫線囲み型** | 記号の線で数字を挟む | `＿＿＿＿＿＿＿ いきなり＜高時給1800円！＞ ＿＿＿＿＿＿＿` |
| **悩み共感型** | 求職者の本音を3行並べ、最後に回収 | `〜したい… 〜でも稼ぎたい… でも〜はイヤ… それ、全部叶います！！` |
| **番号手順型** | 作業を①〜④で書く | `１）マニュアルを確認 ２）工具で穴をあけて金具を取り付ける ３）…` |
| **比喩型** | 既知の物にたとえる | `プラモデルを組み立てるようなイメージです◎` |
| **枠数緊急型** | 残枠を先頭に出す | `＼あの人気工場から枠が出ました！／` / `7月入社枠残り3名となりました・・！` |
| **権威型** | 発注元・グループの規模を先に出す | `東証プライム上場グループで正社員！` |

### 型と、既存の訴求軸との対応

| 型 | 対応 S系 | 備考 |
|---|---|---|
| Q&A型 | S039 相談から開始 | 読み手の疑問を先回りする |
| ハッシュタグ型 | S063 具体フレーム | 条件を分解して並べる |
| 罫線囲み型 | S001 数値実績 | 数字を視覚的に隔離する |
| 悩み共感型 | S056 損失回避フレーム / S065 近接場面 | **年齢を書かずに読み手を絞れる型** |
| 番号手順型 | S063 具体フレーム | 作業の見通しを与える |
| 比喩型 | S070 間接比較 / S065 近接場面 | 未経験の不安を下げる |
| 枠数緊急型 | S045 残数表示 / S044 数量限定 | 変数5と同じ |
| 権威型 | S059 確実性フレーム | **事実確認が要る**（発注元名の掲載可否） |

### ★ 悩み共感型が、年齢訴求の代替になりうる

## 12. 条件欄・共通テンプレート欄の使い方

**2026-08-02 追加。**求人ID 4件分の条件欄を実測した。

### 求人ごとに書き分けている欄

| 欄 | 実測された書き方 |
|---|---|
| **給与** | **月収例と内訳の計算式を必ず書く**（基本給＋残業＋深夜＋通勤手当）。セクション4参照 |
| 勤務形態 | `固定時間制（日勤のみ・土日休み）` / `シフト制（二交替／土日休み）` と**カッコで補足**する |
| 勤務時間 | 交替制は `①8:00-16:50 ②21:00-5:50` と**番号つきで両方書く** |
| 年間休日 | **日数を数字で書く**（121日 / 123日 / 126日） |
| 勤務地備考 | 配属先が複数ある案件は `①〜⑤` で列挙し `※選考時期により変動します。` と添える |
| 試用期間 | 全件 `14日間・同条件` |

### 全求人で同一の欄（派遣元の制度・販促）

| 欄 | 扱い |
|---|---|
| 待遇・福利厚生 | 全4案件で同一の15項目リスト |
| 社会保険 | 同一 |
| その他 | 同一テンプレート（`積極採用中／履歴書不要／WEBで面接OK／…` ＋ 応募〜内定の4ステップ ＋ 会社概要） |
| アピールポイント | 全14件で同一（お仕事相談会の告知）。**ただし時刻表記が壊れている。セクション8-5 参照** |

### ★ 3層モデルとの対応

競合のこの構造は、本スキルの3層モデルと**そのまま対応している。**

| 本スキルの層 | 競合の欄 |
|---|---|
| **層1（派遣元・全案件で不変）** | 待遇・福利厚生 / 社会保険 / その他 / 会社概要 |
| **層2（事業所・恒久）** | 勤務地備考 / 勤務形態 / 年間休日 |
| **層3（案件限り）** | 給与の月収例 / 勤務時間 / 仕事内容 |

**→ 層1にあたる欄は、案件ごとに書き直さない。**FooT でも同じ文面を全求人に載せてよい。
**→ ヒアリングで層1を聞き直さないという既存ルールと、競合の実運用は一致している。**

### 応募〜内定の流れを明記している

競合は全件に `▼応募からお仕事開始までの流れ▼ ①応募 ②面接予約 ③WEB面接 ④内定` を入れている。

**手順が見えると応募の心理的コストが下がる**（S035 入力項目削減の隣接効果）。
**→ FooT でも、実際の選考フローが確認できれば同じ形で書ける。**
**→ 実態と違う手順を書かない。**WEB面接をやっていないなら書かない。
