## 取得のルール（層1の作業）

- **Indeed へのアクセスは Claude Code の WebFetch のみ。**
  `/viewjob?` は `User-agent: *` に対して Disallow。
  **curl / Node / Python / Scrapy / Playwright で巡回しない。**
- **層2（このCodexスキル）にネットワークアクセスを行うコードを含めない。**
- URL は `jk` パラメータのみ残し、トラッキングパラメータ（`tk` / `adid` / `xkcb` 等）は落とす。
- **Indeed のコンテンツを再配布しない。**社内・クライアント向けの分析物として扱う。
- 担当者の直通電話番号は分析に不要。`_source/` に残さない。
