# 文体ルール（媒体本文として自然に読ませる）

**このスキルが文章を書く箇所すべてに適用する。**
職種名・キャッチコピー・仕事内容・求める人材・給与の補足・給与例・勤務時間の補足・休日の補足・
職場環境の補足・福利厚生の補足・選考の補足・試用期間の補足・喫煙の補足。例外はない。

機械判定の正本は `scripts/precheck_doc.py` の `STIFF` 定数。
このファイルは、なぜそう直すのかを書いたもの。両方を直さないと片方だけズレる。

---

## 大原則

### 1. 求人原稿は説明書ではない

読者は「この仕事を選ぶかどうか」を決めに来ている。手続きの説明を読みに来ていない。
だから書き手の都合（想定・確認・整理）を本文に出さない。

```
NG  時給・勤務時間・休日を確認したうえで、リフト資格を活かしたい方に向いています。
OK  フォークリフト運転技能講習修了者。時給2000円、8:00〜17:00、土日休みの条件で、
    リフト資格を活かしたい方に向いています。
```

NG のほうは「確認したうえで」という手続きを読者に命じている。
条件を並べる型（QUEST 数字型）を使うなら、**条件そのものを書く**。
「確認してください」は書かない。条件を書けば読者は勝手に確認する。

### 2. 条件は名詞で置く。動詞で飾らない

```
NG  時給は2000円となっております。
OK  時給2000円。

NG  勤務時間は8時から17時を想定しています。
OK  8:00〜17:00。残業は基本ありません。
```

「〜となっております」「〜を想定しています」は、書き手が条件から距離を取る言い方になる。
条件は言い切る。言い切れないなら、その事実はまだ裏が取れていない（＝書かない）。

### 3. 原稿の外側に言及しない

```
NG  今回の求人では、西尾市内の工場を回る輸送業務は入れません。
NG  本求人は倉庫内作業のみとなります。
OK  倉庫内での出荷作業です。トラックへの積み下ろしはありません。
```

「今回の求人では」「本求人は」は、原稿を作っている側の会話がそのまま漏れたもの。
読者には前回の原稿がない。**無いものは説明できない。**

## 書き換え表

| 出たら直す | 直し方 | なぜ |
|---|---|---|
| 〜を確認したうえで／踏まえたうえで | 条件をそのまま書く | 読者に手続きを命じている |
| 〜となっております／しております | 〜です／言い切る | 硬い。距離ができる |
| 〜を想定しています | 言い切るか、書かない | 想定は書き手の都合 |
| 〜する形になります／という形です | 〜します | 輪郭がぼける |
| 本求人／今回の求人／当求人 | 削る | 原稿の外側 |
| 求職者／応募者の方は／候補者 | あなた、または主語を落とす | 読者を三人称で呼んでいる |
| 〜については、／〜に関しては、 | 削って直接書く | 説明文の接続 |
| 〜という点で／という面で | 削る | 分析口調 |
| 以下のとおり／下記のとおり | 本文に案内は要らない | 媒体には目次がない |

## 長さ

- **1文は60字まで。**超えるものが3つ以上あると読点で息が切れる。
- 読点で繋げず、句点で切る。切ると条件が1つずつ立つ。

```
NG  倉庫内でフォークリフトを使って自動車部品のパレットを運ぶ作業で、作業は10人前後の
    ラインで行い、慣れるまでは先輩が付いて教えるので未経験でも始められます。（68字）
OK  倉庫内でフォークリフトを使い、自動車部品のパレットを運びます。
    作業は10人前後のライン。慣れるまで先輩が付きます。
```

## 欄ごとの入り方

| 欄 | 1文目に置くもの | 置かないもの |
|---|---|---|
| 職種名 | 何をどこで（機械・扱う物） | 金額・時刻・条件 |
| キャッチコピー | 読者が一番先に知りたい条件 | 「募集中」「大募集」 |
| 仕事内容 | その日の最初の動作 | 会社紹介・理念 |
| 求める人材 | 資格・経験の有無 | 年齢・性別・「若い方」 |
| 給与の補足 | 内訳（基本＋手当） | 「頑張り次第」 |
| 勤務時間の補足 | 実時間と残業の有無 | 「応相談」だけ |

**年齢・性別は応募資格として書けない**（雇用対策法10条・男女雇用機会均等法5条）。
「20代・30代が活躍中」は職場情報タグ（No.23）に置く。本文には書かない。
狙った年代に届かせたいなら、その年代が反応する**条件**を書く。

```
NG  20代・30代が活躍中の職場です。
OK  フォークリフトの資格が活かせて、残業は基本なし。土日休みです。
```

## 情報が足りないとき

**説明を増やして字数を埋めない。**
条件を4つの欄で言い換えて反復すると、読者は同じことを4回読む。
足りないなら、先に事実を取りに行く。

1. `scripts/collect_siblings.py` で同じ派遣先の他求人から事実を拾う
2. それでも足りなければヒアリングで聞く
3. それでも足りない欄は、**今の掲載値を残す**（書けないことと消すことは別）

`precheck_doc.py` の P9（同じ言い回しが3欄以上）と P8（目標字数）は、
この順番を飛ばして字数だけ合わせたときに鳴る。
