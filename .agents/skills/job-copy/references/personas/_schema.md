# 求人ペルソナ骨格スキーマ

`カズキ.md`の11章構成だけを転用する。別事業の心理記述は転用せず、FooT求人の根拠が入るまで各章を`MISSING`とする。

## 共通メタデータ

- ファイル先頭に`status: skeleton`を書く。
- 骨格段階では、各章の本文を`MISSING`の1語だけにする。
- 心理仮説を確定診断として扱わず、コピーで直接言い当てない。
- `CANDIDATE`の情報を生成根拠に使わない。
- ペルソナの作成・更新責任は層1に残す。

## 11章マッピング

| 章 | 元見出し | 求人ペルソナでの役割 |
|---|---|---|
| 1 | 一枚サマリー | ペルソナの識別 |
| 2 | 表の顔と裏の顔 | 生活導線と、いつ求人を見るか |
| 3 | 7つの痛み | 訴求軸の優先順位付けの根拠 |
| 4 | 本音の欲求 | 機能・感情・社会の3面から主訴求を選ぶ根拠 |
| 5 | 行動原理と深層心理 | 心理仮説。確定診断や直接言い当てるコピーには使わない |
| 6 | 自己破壊ループ | 応募に至らない構造 |
| 7 | 恐怖と表裏一体の強み | 計画書§10-2で役割未定義。見出しだけ保持し、定義されるまで使わない |
| 8 | 情報収集・検索行動 | 求人検索キーワード辞書 |
| 9 | 購買行動 | 応募理由と応募離脱要因 |
