# job-copy（求人原稿システム）

既存の求人原稿を見直し、5案（A〜E）を作り、選んだ1案を**事務員がAirワークへそのままコピペできる出稿用ドキュメント**にするためのスキル一式です。

このリポジトリは1社専用です（clientId: `foot`）。

## 最初にやること

**`.agents/skills/job-copy/SETUP.md` を開いて、上から順に進めてください。**

Windowsの方は「手順0. WSL2を用意する」から始まります。ここを飛ばすと後の手順がすべて失敗します。

## フォルダが空に見えるときは

中身は `.agents` という**先頭がドット（`.`）のフォルダ**に入っています。ドットで始まるフォルダは、Windowsのエクスプローラーでも macOS の Finder でも、初期設定では表示されません。**中身が無いわけではありません。**

- Windowsのエクスプローラー: 「表示」タブ →「隠しファイル」にチェック
- macOSのFinder: `command` + `shift` + `.`
- ターミナル: `ls -a` で確認できます

Codex に作業フォルダを開かせれば、隠しフォルダのままでも問題なく動きます。

## 中身

```text
.agents/skills/job-copy/
├── SETUP.md       ← 導入手順。最初に読む
├── SKILL.md       ← 実行手順。Codexがこれを読んで動く
├── scripts/       ← 実際に動くプログラム
├── references/    ← 判断のもとになる資料（項目の対応表、質問集など）
├── assets/        ← 出力の雛形
└── agents/        ← 補助役の定義
```

## 更新の受け取り方

スキルが更新されたら、作業フォルダで次を実行すれば最新になります。

```bash
cd ~/job-copy-work && git pull
```

## 触らないこと

- **このリポジトリのファイルを直接書き換えないでください。**次の更新配布ですべて上書きされます。
- 直したいところ・おかしいところが見つかったら、市野に連絡してください。こちら側で直して配布します。
- **`references/clients/foot/config.json` も手で編集しないでください。**どのスプレッドシートを読み書きするかはここに書いてあり、登録済みの状態で配布されます。`SETUP.md` 手順3でやるのは、その登録先が自分の環境から開けるかどうかの確認（`init_client.py --check`）だけです。
- 中身がおかしいと思ったら、書き換えずに市野へ連絡してください。手で直しても次の配布で上書きされます。

## 困ったとき

`SETUP.md` の「7. 困ったとき」に、よくあるエラーと対処を書いてあります。そこにない場合は、**実行したコマンドと画面に出たメッセージをそのまま**市野に送ってください。
